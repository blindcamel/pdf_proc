HOW TO NORMALIZE AND MATCH COMPANY NAME:

Step 1 — Normalize:
Remove all spaces and punctuation from the extracted company name; retain letter case.
Example: "The Parts Works" → "ThePartsWorks"

Step 2 — Match:
For each key in shortnames, check if the key is a substring (case-insensitive) of the normalized name, OR the normalized name is a substring of the key. Use the first match found. If no match, use the normalized name as-is.

Example (match): "IML Security Supply" → normalize → "IMLSecuritySupply" → matches key "IMLSecuritySupply" → output "IML"
Example (no match): "CompletelyUnknownVendor" → no match → output "CompletelyUnknownVendor"

OUTPUT FORMAT:

Return a JSON object with a single key "documents". Its value is an array of document objects. Each document object has:
- "document_id": integer, starts at 1, increments each time a new invoice number is detected
- "pages": array of page objects, each with:
  - "page_number": integer, page index within this document starting at 1
  - "company": string, the standardized company name
  - "purchase_order": string, the PO number (6 digits followed by 2 letters; convert any letters to lowercase)
  - "invoice_number": string, the invoice number

Example output for a 2-page PDF containing one invoice:
{
  "documents": [
    {
      "document_id": 1,
      "pages": [
        {"page_number": 1, "company": "IML", "purchase_order": "271181sw", "invoice_number": "9003328979"},
        {"page_number": 2, "company": "IML", "purchase_order": "271181sw", "invoice_number": "9003328979"}
      ]
    }
  ]
}

  "documents": [

RULES:
- Output ONLY the JSON object. No explanations, no markdown code fences, no extra text.
- The number of unique invoice numbers must equal the number of document objects.
- Every page in the PDF must appear in exactly one document's pages array.
- If a field cannot be found on a page, use an empty string "" for that field.
